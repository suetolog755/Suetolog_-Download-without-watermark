# 🎬 Видео-бот без водяных знаков

Telegram бот для скачивания видео с Instagram, YouTube, Facebook, Twitter без водяных знаков.

## Возможности

- 📸 **Instagram** — Reels, посты, IGTV
- 🎥 **YouTube / YouTube Shorts** — любое качество
- 📘 **Facebook** — видео из постов
- 🐦 **Twitter / X** — видео из твитов

## Установка

### Требования
- Python 3.11+
- FFmpeg

### Запуск локально

```bash
git clone https://github.com/suetolog755/Suetolog_-Download-without-watermark.git
cd Suetolog_-Download-without-watermark
pip install -r requirements.txt
python bot.py
